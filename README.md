# GTA 6 Agent Mishap Line

One-sentence entry for make.fun's **"Funniest AI Agent Mishap: GTA 6 Launch Week"** competition.

The entry is the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week — in a single sentence of at most 240 characters.

## Run

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt`.

## Entry
